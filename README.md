# Contact Manager API

A simple **RESTful API** built with **Node.js (Express)** and **MongoDB (Mongoose)** to manage contact information.  
Live: https://contactmanagerapi-q2tq.onrender.com

---

## 🚀 Features
- Add, view, update, and delete contacts  
- Filter contacts by last name (`/contacts?lastName=Smith`)  
- Get a single contact by ID (`/contacts/:_id`)  
- MongoDB Atlas + Render deployment  

---

## 🛠️ Tech Stack
- Node.js + Express  
- MongoDB (Mongoose)  
- Deployed on Render
